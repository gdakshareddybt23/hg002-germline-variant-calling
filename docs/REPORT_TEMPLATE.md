# Project results report (fill only after running)

## Scientific question
How do GATK HaplotypeCaller and FreeBayes differ in germline SNP and indel discovery on a small, publicly available HG002/GRCh38 chromosome 20 region?

## Methods
- Sample: HG002 / NA24385. Specify original read provider, read technology, download date.
- Reference: local 500,001-bp GRCh38 chromosome 20 slice, original interval chr20:10,000,000–10,500,000 inclusive. Slice coordinate origin is shifted.
- QC: FastQC + MultiQC; discuss warnings and decisions.
- Alignment: BWA-MEM, `@RG` read group `SM:HG002`.
- BAM: SAMtools sorting, indexing, flagstat; GATK MarkDuplicates.
- Germline callers: GATK4 HaplotypeCaller, FreeBayes with default diploid calls.
- Postprocessing: BCFtools normalization, PASS/raw handling and any thresholds.
- Validation: benchmark only with verified matching GIAB truth VCF and high-confidence BED. RTG vcfeval sample matching/representation-aware evaluation.
- Visualization: IGV custom local FASTA and read evidence at selected loci.

## Interpretation
What changed between callers? Is raw variant agreement different from true accuracy? What makes an apparent indel challenging? Are differences possibly caused by representation, filtering, local assembly, haplotype handling, read depth or mapping errors?

## Limitations
- Small region, one sample; no generalization to clinical WGS or somatic calling.
- Variant filters used as learning examples, not validated clinical thresholds.
- Benchmark values not valid unless matched truth set, matched confident BED, and coordinate system verified.
- Gene/consequence annotation is optional: export VCF using `scripts/05_export_for_vep.py` and annotate against GRCh38 using Ensembl VEP. Validate coordinates/REF alleles against the actual GRCh38 reference first and document the release and database versions.
